💻 Module 1: Foundations & Architecture of Computing

1.1 Data, Information, and Knowledge

  • Data: Raw, unorganized facts, figures, or symbols without context (example: 40, 39, 42).
  • Information: Data that has been processed and organized to become meaningful (example: the average classroom temperature is 40°C).
  • Knowledge: Understanding and applying information to make decisions or solve problems.

1.2 Characteristics of Computers

CharacteristicDescription
SpeedPerforms calculations in very short periods of time.
AccuracyProduces accurate results when instructions and input data are correct.
DiligenceCan repeat tasks consistently without becoming tired.
VersatilityCan perform many different kinds of tasks.
Storage CapacityCan store large amounts of data and information.

1.3 Four Cognitive Categories of the Human Mind

  1. Data Processing / Sensing: Receiving information from the environment.
  2. Memory / Retention: Keeping facts, experiences, and information.
  3. Reasoning / Logic: Analyzing information and evaluating possible solutions.
  4. Creativity / Intuition: Producing new ideas and original work.

1.4 History and Classification of Computers

Generations: First—Vacuum Tubes; Second—Transistors; Third—Integrated Circuits; Fourth—Microprocessors; Fifth—Artificial Intelligence and advanced computing.

  • Supercomputers: High-performance computers used for complex scientific calculations.
  • Mainframes: Large systems used for high-volume data processing.
  • Minicomputers: Mid-range multi-user computers.
  • Microcomputers: Personal computers such as desktops, laptops, and mobile devices.

1.5 Forms of Computing

  • Parallel Computing: Multiple processors execute parts of a problem at the same time.
  • Distributed Computing: Separate computers communicate over a network to complete a shared task.
  • Computing Environments: Personal computing, client-server, peer-to-peer, and cloud computing.

📊 Module 2: Information Systems & Data Modelling

2.1 What is an Information System?

An Information System (IS) is an organized combination of hardware, software, data, people, and procedures that collects, processes, stores, and distributes information to support decisions and control.

2.2 Five Core Components of an Information System

  1. Hardware: Physical devices and equipment, such as computers, servers, and storage drives.
  2. Software: Programs and applications that instruct hardware what to do.
  3. Data: Raw facts and records processed into useful information.
  4. Procedures: Rules and steps for operating and using the system.
  5. People: Users, operators, analysts, and administrators who interact with the system.

2.3 Databases and Entity-Relationship Modelling

A database is an organized collection of related data that can be accessed, managed, and updated.

  • Strong Entity: Can exist independently and has its own identifying key.
  • Weak Entity: Depends on another entity for its identification or existence.
  • Attributes: Properties that describe an entity, such as Student ID, Name, and Email.
  • Relationships: Associations between entities:
    • One-to-One (1:1): One record relates to one record.
    • One-to-Many (1:M): One record relates to multiple records.
    • Many-to-Many (M:N): Multiple records relate to multiple records; usually resolved using a junction table.

🗄️ Module 3: Database Management & MySQL Commands

3.1 Database Management Systems

A Database Management System (DBMS) is software that allows users and applications to create, access, update, and manage databases while supporting security and data integrity.

3.2 SQL Component Languages

  • DDL (Data Definition Language): Defines or changes database structures. Examples: CREATE, ALTER, DROP, TRUNCATE.
  • DML (Data Manipulation Language): Adds or changes stored data. Examples: INSERT, UPDATE, DELETE.
  • DQL (Data Query Language): Retrieves data. Example: SELECT.

3.3 Essential MySQL Code Snippets

OperationExample SQL
Create a table 
CREATE TABLE Students (
  StudentID INT PRIMARY KEY,
  FirstName VARCHAR(50) NOT NULL,
  GPA DECIMAL(3,2),
  MajorID INT
);
Insert a record 
INSERT INTO Students (StudentID, FirstName, GPA, MajorID)
VALUES (101, 'Alice', 3.85, 2);
Query records 
SELECT FirstName, GPA
FROM Students
WHERE GPA >= 3.5
ORDER BY GPA DESC;
Aggregate and group 
SELECT MajorID, AVG(GPA) AS AverageGPA
FROM Students
GROUP BY MajorID;

💾 Module 4: Hardware, Memory & System Storage

4.1 Von Neumann Architecture

A common computer architecture consists of the Central Processing Unit (CPU), memory, and input/output (I/O) devices.

  • Control Unit (CU): Directs processor operations and coordinates the fetch-decode-execute cycle.
  • Arithmetic Logic Unit (ALU): Performs arithmetic and logical operations.
  • Registers: Very fast storage locations inside the CPU.

4.2 Memory Hierarchy

Memory TypeVolatilityFunction
RegistersVolatileVery small, very fast storage inside the CPU.
Cache (L1/L2/L3)VolatileStores frequently used data and instructions for quick access.
RAMVolatileTemporarily stores programs and data currently in use.
HDD / SSDNon-volatileStores files and programs even when power is off.

🌐 Module 5: Data Communications & Networking Infrastructure

5.1 Network Topologies

  • Star Topology: Devices connect to a central hub or switch. If the central device fails, communication may be interrupted.
  • Mesh Topology: Devices have multiple connections, providing alternative paths but requiring more resources.
  • Bus Topology: Devices share a common communication cable called a backbone.
  • Ring Topology: Each device connects to two neighboring devices, forming a loop.

5.2 Network Classification

  • LAN (Local Area Network): Covers a small area such as a home, office, or school building.
  • MAN (Metropolitan Area Network): Covers a city or large campus.
  • WAN (Wide Area Network): Covers large geographic areas, countries, or continents.

5.3 OSI Reference Model

  1. Physical: Transmits raw bits through a physical medium.
  2. Data Link: Transfers frames between directly connected devices.
  3. Network: Handles logical addressing and routing.
  4. Transport: Supports end-to-end delivery and transport reliability.
  5. Session: Establishes, manages, and ends communication sessions.
  6. Presentation: Handles data formatting, encryption, and compression.
  7. Application: Provides network services to user applications, such as web and email services.

5.4 Common Network Devices and Protocols

  • Router: Forwards data between networks.
  • Switch: Connects devices within a local network.
  • Modem: Connects a network to an internet service provider's connection.
  • TCP/IP: A suite of protocols used for communication across networks.
  • HTTP/HTTPS: Protocols used to transfer web content.
